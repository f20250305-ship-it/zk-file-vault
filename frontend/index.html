Cryptographic Threat Model & Zero-Trust Architecture

How ZeroVault guarantees data privacy, integrity, and confidentiality against untrusted servers and network eavesdroppers:

🔒
Client-Side Authenticated Encryption
All files and filenames are encrypted using AES-256-GCM directly in the browser via native WebCrypto. GCM includes an authenticated tag to immediately detect any MITM tampering or bit-flipping attacks.
🌐
RFC 3986 URL Hash Key Isolation
The 256-bit decryption key is placed strictly in the URL fragment (#key=...). Per HTTP specifications, browsers never transmit fragments to the server in request headers, preserving zero server knowledge.
🔥
Cryptographic Data Shredding
When a file reaches its download limit or TTL expiration, the server overwrites the storage blocks with random entropy (secrets.token_bytes) before unlinking, preventing cold recovery.
🛡️
Blind Server Architecture
Even if the server filesystem or database were completely compromised by an attacker, the attacker would gain access only to unkeyed AES-256 ciphertext blobs with 0% plaintext leakage.
